# Replication package

*What a Pooled Leaderboard Does Not Say: Auditing the Scope and Provenance of Method Comparisons in Microservice RCA Benchmarks* (anonymous submission).

This package lets a reviewer (1) regenerate every number, table, and figure of the paper from the per-case table in a few minutes, and (2) see, for every run, which code, input, and environment produced it, so that the runs can be repeated from the public benchmark data.

## Contents

| Path | What it is |
|---|---|
| `data/merged_long.csv` | The per-case table: 19,893 rows, one per (method, case, seed, condition). Columns: `family, release, subsystem, subsystem_id, case, q_idx, case_id, fault, method, seed, impl_source, role, input_repr, window_min, score, score_strict, valid_output, source_file`. `score` is the case score used in the paper (top-1 hit; OpenRCA partial credit), `valid_output` marks invalid outputs (scored 0), `role` separates published methods, probes, shipped baselines, and diagnostic runs. |
| `data/runs_ledger.csv` | One row per run file: method, dataset, input file, code commit, environment, run time, number of cases, coverage, recomputed accuracy, status. |
| `data/fault_labels_openrca_petshop.csv` | Fault classes of the OpenRCA and PetShop cases, extracted from the benchmarks' ground truth (used by the fault-composition analysis). |
| `data/inputs/` | The two published tables that the paper re-analyses (RCAEval Table 6, arXiv 2412.17015; PetShop Table 8, arXiv 2311.04806), as the text lines that the parser reads. |
| `per_case_outputs/` | The run files that the table was built from (rankings or answers per case), at the paths given in `source_file`. |
| `analysis/` | Analysis scripts: `rq1_main.py` (paired differences, bootstrap CIs, reversals, random-effects PIs, interaction tests), `rq1_extra.py` (published tables, regret), `rq2_main.py`, `rq2_fault.py` (RQ2 factors), `rq3_holdout.py` (held-out subsystems), `rq1_crossfamily.py` (cross-family set), `rq1_bonferroni.py` (Bonferroni-adjusted check of the reversals). |
| `paper/` | LaTeX source of the paper and the scripts that turn the analysis outputs into `numbers.tex` (every number in the text is a macro), the tables, and the figures. `paper/data/` holds the analysis outputs as generated by `quickcheck.sh`. |
| `scripts/verify_main_text_numbers.py` | Checks that every computed number in the text is a macro from `numbers.tex` and that every remaining literal has a documented source. |
| `additional_tables.pdf` | Additional tables and diagnostics: probe definitions, OpenRCA wrapper, the under-specified input choice and the two silent failures in RCAEval, CausalRCA and SimpleRCA runs, window diagnostic, margin and spread, held-out and cross-family details (including the interaction tests and per-seed results), the survey (paper list, per-system reporting check, release check), and complete result tables. |
| `survey/` | Reporting-practice survey: the paper list (`papers.csv`, 26 papers; `excluded.csv`, the three without full text, not counted), the per-system reporting check of the 23 full-text papers (`per_system.csv`: whether a multi-system paper reports a score per system, and the table, figure, or passage checked), and the release check of per-case outputs, done on 2 October 2026 (`release_check.csv`, one row per paper with the commit checked; `release_check_notes.md`, the links and files found per paper). Full texts of the papers are not included. |
| `run_scripts/` | Scripts that produced the runs (`merged/`: run, registration, and diagnostic scripts of the audit; `rcaeval_repo/`: scripts placed in the RCAEval repository; `openrca_eval/`: probes and the OpenRCA wrapper; `petshop/`, `simplerca_port/`). |
| `envs/` | `pip freeze` and Python version of each environment (`auditstack`: analysis and probes; `rcaeval_rcd`: RCD and CausalRCA; `petshop`; `simplerca`; `ts`). |

## Quick check (a few minutes, CPU only)

```bash
pip install numpy pandas scipy statsmodels matplotlib   # versions in envs/auditstack.txt (Python 3.11)
./quickcheck.sh                                          # or PYTHON=/path/to/python ./quickcheck.sh
```

It re-runs all analyses on `data/merged_long.csv` (bootstrap B = 10,000, seed 20260929), regenerates `paper/numbers.tex`, the tables, and the figures, compares `numbers.tex` with the shipped version, and runs the number check. Expected output ends with `numbers.tex: identical to the shipped version` and `ALL CHECKS PASS`.

## Full rerun (from the public benchmark data)

The benchmark data are not redistributed. Obtain them from their sources: RCAEval (repository at commit `497505b`, datasets RE1 and RE2), OpenRCA (official dataset), PetShop (official dataset and harness). For every run file in `per_case_outputs/`, `data/runs_ledger.csv` gives the code commit, input file, environment, and arguments; the scripts are in `run_scripts/`. The scripts contain the paths of our machine, replaced by `$HOME`, `$AUDIT_ROOT`, and `$CONDA_ENVS`; adapt them to your setup. Randomized methods (RCD, CausalRCA) were run with seeds 0, 1, 2. CausalRCA requires scikit-network 0.31.0 (see paper §3.3).

## Anonymization

For double-anonymous review, file paths, user and host names, and internal project labels were replaced in every text file of this package (including `impl_source`, `input_repr`, and `source_file` in the table). All other columns are identical to the frozen table used for the paper; the digest of the released table is the one printed in the paper (SHA-256 prefix `78b24273`). The analysis scripts check this digest.

## LLM tools

The scripts in this package were written with LLM coding assistants from specifications by the authors; see paper §3.5. No LLM produced or scored a method output.

- `paper/data/supp/table_shapes.json`: number of columns and of data rows of every RCAEval metric table we read (min and max over all cases of each table kind), produced by `scripts/table_shapes.py` on the benchmark data; read by `make_numbers.py` for the column and row ranges quoted in paper Sections 3.3 and 4.2.
- `paper/data/supp/baro_re2_top1.json`: diagnostic on BARO's RE2 outputs (first-ranked metric per case, top-3 accuracy, column counts of the RE1 and RE2 metric tables), produced by `scripts/baro_re2_top1.py` from the stored run outputs; read by `make_numbers.py` for paper Section 4.2.
